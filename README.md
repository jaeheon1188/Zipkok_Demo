# zip콕 (Zipkok) — Frontend

## 프로젝트 소개

**zip콕(Zipkok)**은 중고거래 등 개인 간 택배 거래에서 발생할 수 있는 실제 주소 노출 문제를 해결하기 위한 가상주소 기반 개인정보 보호 서비스입니다.

전화번호를 안심번호로 보호하는 것처럼, 거래 시 실제 주소 대신 일회용 가상주소 코드를 사용하여 판매자와 구매자의 개인정보 노출을 최소화하는 것을 목표로 합니다.

또한 중고거래 플랫폼이 실제 주소를 직접 보관하지 않고, 별도의 zip콕 시스템에서 주소를 암호화하여 관리하는 **'주소계의 PG(Payment Gateway)' 구조**를 지향합니다.

## 개발 목적

본 저장소는 zip콕 캡스톤 디자인 프로젝트의 **프론트엔드 UI 구현 및 학습**을 위한 개인 작업 공간입니다.

HTML과 CSS를 중심으로 사용자가 서비스를 직관적으로 이용할 수 있는 웹페이지를 제작하고, 향후 백엔드 시스템과 연동할 수 있는 화면 구조를 구성하는 것을 목표로 합니다.

## 주요 구현 예정 기능

- **서비스 소개 화면:** zip콕의 서비스 목적 및 이용 방법 안내
- **주소 입력 화면:** 판매자 및 구매자의 배송지 정보 입력 UI
- **가상주소 표시 화면:** 실제 주소 대신 SAFE 코드 표시
- **거래 진행 화면:** 택배 예약 및 배송 진행 상태 표시
- **배송 완료 화면:** 거래 완료 및 가상주소 만료 안내

※ 현재는 화면 구현을 중심으로 개발하며, 실제 주소 암호화·가상주소 발급·데이터베이스 관리는 별도의 백엔드에서 처리하는 구조를 목표로 합니다.
